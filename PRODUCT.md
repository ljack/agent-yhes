# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Scope

This product record describes the educational web tutorial. The agent-yhes
protocol, CLI and native macOS signer remain separate implementations.

## Stack

The user requested an HTML app. This implementation uses static HTML, CSS and
JavaScript with local SVG diagram geometry, no framework or remote service.
This is an implementation choice, not a project-wide stack policy.

## Users and purpose

People learning how to get agents working together across harnesses. The tutorial
should explain the concept, usage and first setup through two people's terminals
and visible command/data movement. The user asked for a clean view with limited
detail and optional short Why explanations.

## Content and constraints

Explain human, terminal, harness, agent, LLM, local Git, shared Git repository,
JetStream, biometrics and encryption as distinct responsibilities. Preserve the
implemented Git-first ordering, human/agent provenance and exact human approval.
An active listener can wake; a dormant model is not started by the protocol.
The current same-Mac lab simulates human consent using disposable keys.

The web page is an illustrative walkthrough, not a shell, live lab dashboard,
cryptographic implementation or biometric authenticator. No credentials, keys
or real participant messages are requested. Author-created example content is
labelled as a visual demo.

## Evidence

BOOTSTRAP.md, docs/TEAM-PILOT.md, docs/NEW-MEMBER-AGENT.md and
docs/VALIDATION.md contain the runnable workflows and executed checks.

## Surface assumption

The first pass is guided with editable example terminals; free-form exploration
was offered as an optional preference. This default is not recorded as a user
decision about future interfaces.
