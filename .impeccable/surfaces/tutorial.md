# Interactive tutorial

Mode: Read with step controls. Scope: tutorial/index.html, tutorial/style.css,
tutorial/model.js, tutorial/app.js. The user specified two terminal/person lanes,
visible flows, named actors and a clean presentation with optional Why details.
This is a code-first app/document surface; no workflow default is stored.

## Direction contract

THESIS: Make authorship and transport visible in a stable two-person diagram.
The terminal is part of the explanation, with one active operation at a time.

OWN-WORLD: Inherit the native client's clear system typography and restrained
controls. A pale cool workspace supports dark code terminals; indigo identifies
Alice, teal identifies Bob. Shared infrastructure stays neutral. Solid edges
carry accepted records; dashed edges convey reasoning/notification.

STORY: Connect identities, send an agent message, preserve a human original,
then see why delayed notification does not lose the Git record. Details are
progressively disclosed, never all expanded in the initial view.

FIRST VIEWPORT: Two stable terminal lanes around a narrow shared repository and
JetStream column. Local harness/agent/model and crypto/Git tools sit under their
terminal. Chapter selection, narration and transport controls precede the map
so playback remains discoverable on short screens. Why stays collapsed.

FORM: User-specified twin-terminal diagram, extending the existing product's
restrained app language. No concept tournament or image comp is needed for this
specified composition. Mobile stacks the same actors in reading order.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
